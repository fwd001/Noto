### 两个环境坑（本机实测，下次直接绕开）

1. **`pnpm` shim 坏**：`package.json` 的 `packageManager` 是 `pnpm@12.5.1`，全局装的是 `pnpm 11.16.0`
   ⇒ `pnpm test` 报 `'"D:\.pnpm-store\...\pnpm"' 不是内部或外部命令`，且**`pnpm test 2>&1 | tail` 的
   `$?` 取到的是 `tail` 的退出码 0，会把失败伪装成通过**。依赖已装在 `apps/desktop/node_modules`，
   直接跑 `./node_modules/.bin/vitest.cmd run` 即可。
2. **arch-check 两条假红**：`hygiene:include-paths-tracked` 与 `hygiene:no-ignored-source-file`
   报 `spawnSync git EBUSY` / `git ls-files 跑不动`。同一条 `git ls-files` 在 Bash 里手动跑**正常**（349 个文件）。
   ⇒ 这是 node 子进程拿 git 索引时的沙箱争用，不是缺陷。已独立验证：8 个 `include_str!("../../../migrations/*.sql")`
   目标全部在版本库内；`.gitignore` 只忽略 `apps/*/src-tauri/gen/`（生成目录，正确）。
   **读数纪律**：这台机器上arch-check 的两红先按假红处理，但要像这次一样手工验一遍再落账。
